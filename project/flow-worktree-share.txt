# This project's own git-excluded paths, added to the ones
# ~/.flow-factory/worktree-share.txt already lists. flow-worktree-create reads
# the machine file first, then this one.
#
# This file is optional. A project with no extra paths does not have it, and
# the skill links the machine defaults and says nothing.
#
# It is a file rather than a key in flow-factory.toml because the machine file
# is already a path list with a format, and a second list in a different
# notation would be two shapes for one thing.
#
# Format is the machine file's: one repo-relative path per line, no trailing
# slash, no inline comment, `#` lines and blanks ignored, newline at the end.
#
# The nesting rule. Never add a path that sits inside a folder the machine file
# already links. `.flow` is linked as a folder, so `.flow/anything` is refused.
# Through that link the destination is the source, so such a line can never do
# anything: it prints a skip that reads like success. The skill refuses it and
# names it; this header is so you do not write one in the first place.
